# Email & Account Metrics SQL Analysis

# Опис проєкту

  У  цьому проєкті було виконано SQL-аналіз даних про акаунти користувачів та email-активність. Основна мета — об’єднати інформацію про створені акаунти, надіслані email-повідомлення, відкриття листів та переходи з email по країнах, щоб визначити найактивніші країни за кількістю акаунтів і email-взаємодій.

Запит побудований за допомогою **Common Table Expressions (CTE)**, що дозволяє зробити структуру коду зрозумілою, логічною та зручною для подальшого аналізу.

**Що було зроблено**

Зібрано інформацію про email-активність користувачів:

1. кількість надісланих листів;
2. кількість відкритих листів;
3. кількість переходів з email.

**Зібрано інформацію про акаунти користувачів:**

1. країна користувача;
2. інтервал надсилання листів;
3. статус верифікації;
4. статус відписки від розсилки.

**Об’єднано дані по акаунтах та email-подіях за допомогою UNION ALL.**

**Розраховано загальні метрики по кожній країні за допомогою віконних функцій.**

**Виконано ранжування країн за:**

1. загальною кількістю акаунтів;
2. загальною кількістю надісланих email.

**Виведено країни, які входять у топ-10 за кількістю акаунтів або за кількістю надісланих email.**

# Використані SQL-підходи
1. WITH / CTE для поетапної побудови запиту;
2. JOIN для об’єднання таблиць;
3. LEFT JOIN для збереження email-повідомлень навіть без відкриттів або переходів;
4. COUNT(DISTINCT ...) для коректного підрахунку унікальних подій;
5. UNION ALL для об’єднання різних типів метрик;
6. SUM() OVER(PARTITION BY ...) для розрахунку загальних показників по країнах;
7. DENSE_RANK() для ранжування країн;
8. фільтрація топ-10 країн за ключовими бізнес-метриками.

**Бізнес-цінність аналізу**

Цей аналіз допомагає визначити країни з найбільшою кількістю користувачів та найвищою email-активністю. Такі дані можуть бути корисними для маркетингової команди, щоб краще розуміти, у яких країнах email-комунікація працює найактивніше, де є найбільша база акаунтів та які ринки можуть мати найбільший потенціал для подальших кампаній.

**Результати можуть використовуватися для:**

1. пріоритизації країн для email-маркетингу;
2. аналізу залученості користувачів;
3. оцінки ефективності email-кампаній;
4. пошуку ринків із високим потенціалом;
5. подальшого аналізу open rate та click-through rate.

# Результат

Фінальний SQL-запит формує таблицю з агрегованими метриками по країнах, датах, статусах акаунтів та email-активності. У результаті відображаються країни, які входять у топ-10 за кількістю акаунтів або за кількістю надісланих email-повідомлень.
